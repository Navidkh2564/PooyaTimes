# PooyaTimes

PooyaTimes یک پلتفرم خبری و آموزشی با تمرکز بر **آمادگی کنکور** است.

## وضعیت پروژه

🚧 پروژه در حال توسعه است.

ساختار اولیه، طراحی واکنش‌گرا و نسخه ابتدایی سامانه خبر پیاده‌سازی شده است. مدیران می‌توانند دسته‌بندی و خبر ایجاد کنند و خبرهای منتشرشده به‌صورت خودکار در صفحه اصلی و آرشیو اخبار نمایش داده می‌شوند.

## تکنولوژی‌ها

* Python
* Django
* HTML
* CSS
* SQLite

## هدف پروژه

هدف PooyaTimes ایجاد یک پلتفرم جامع برای دانش‌آموزان کنکوری است که شامل:

* اخبار کنکور و آموزش
* مطالب آموزشی
* آزمون‌ها
* منابع مطالعاتی
* ابزارهای کمک‌آموزشی

باشد.

## راه‌اندازی و اجرا

محیط مجازی را ایجاد و وابستگی‌ها را نصب کنید:

```bash
python -m venv venv
venv/Scripts/python -m pip install -r requirements.txt
```

پایگاه داده را آماده کنید:

```bash
venv/Scripts/python manage.py migrate
```

برای مدیریت محتوا یک حساب مدیر بسازید:

```bash
venv/Scripts/python manage.py createsuperuser
```

سپس سرور توسعه Django را اجرا کنید:

```bash
venv/Scripts/python manage.py runserver
```

سایت در `http://127.0.0.1:8000/` و پنل مدیریت در
`http://127.0.0.1:8000/admin/` در دسترس است.

## مدیریت خبرها

1. در پنل مدیریت یک دسته‌بندی بسازید.
2. یک خبر ایجاد کنید و نویسنده و دسته‌بندی آن را انتخاب کنید.
3. وضعیت خبر را روی «منتشرشده» قرار دهید.
4. برای نمایش برجسته در صفحه اصلی، گزینه «خبر ویژه» را فعال کنید.

خبرهای پیش‌نویس و خبرهایی که زمان انتشارشان در آینده است در سایت عمومی نمایش داده نمی‌شوند.

### تصویر و فایل در خبر

- برای تصویر بالای خبر از فیلد «تصویر اصلی» استفاده کنید.
- برای قراردادن تصویر میان متن، در بخش «متن‌ها و تصاویر داخل خبر» چند ردیف بسازید.
- هر ردیف باید فقط شامل متن یا تصویر باشد و «ترتیب نمایش» جای آن را مشخص می‌کند.
- برای نمونه، ترتیب ۱ متن، ترتیب ۲ تصویر و ترتیب ۳ متن، تصویر را میان دو بخش متن نمایش می‌دهد.
- توضیح اختیاری هر تصویر در فیلد «توضیح تصویر» نوشته می‌شود.
- فایل‌های PDF، Office یا ZIP را در بخش «فایل‌های قابل دانلود» اضافه کنید.

حداکثر حجم هر تصویر ۸ مگابایت و هر فایل پیوست ۲۰ مگابایت است. فایل‌های بارگذاری‌شده در پوشه `media/` ذخیره می‌شوند و نباید به Git اضافه شوند.
