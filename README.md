# PooyaTimes

PooyaTimes یک پلتفرم خبری و آموزشی با تمرکز بر **آمادگی کنکور** است.

## وضعیت پروژه

🚧 پروژه در حال توسعه است.

در حال حاضر ساختار اولیه پروژه با Django ایجاد شده و صفحه اصلی سایت در حال طراحی است.

## تکنولوژی‌ها

* Python
* Django
* HTML
* CSS
* SQLite

## هدف پروژه

هدف PooyaTimes ایجاد یک پلتفرم جامع برای دانش‌آموزان کنکوری است که شامل:

* اخبار کنکور و آموزش
* مطالب آموزشی
* آزمون‌ها
* منابع مطالعاتی
* ابزارهای کمک‌آموزشی

باشد.

## اجرا

ابتدا محیط مجازی را فعال کنید:

```bash
source venv/Scripts/activate
```

سپس سرور توسعه Django را اجرا کنید:

```bash
python manage.py runserver
```

سایت در آدرس زیر در دسترس خواهد بود:

`http://127.0.0.1:8000/`
